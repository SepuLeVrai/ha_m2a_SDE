# Release v0.1.6

## Objectif

Version de finition visuelle de l'intégration Home Assistant **m2A Eau**.

## Changements

- nouvelle icône locale dédiée à l'intégration ;
- identité visuelle plus claire dans Home Assistant et HACS ;
- conservation du mécanisme de branding local disponible à partir de Home Assistant 2026.3 ;
- aucun changement fonctionnel sur l'API, les capteurs ou l'historique.

## Compatibilité

La version minimale Home Assistant reste inchangée. Le branding local est pris en charge par Home Assistant 2026.3 et versions ultérieures.

## Qualité

La release est publiée uniquement après validation HACS et Hassfest sur la branche de préparation.
