# GitHub repository settings required by HACS

HACS validates repository metadata in addition to files.

## Topics

On the GitHub repository page:

1. Open the repository `SepuLeVrai/ha_m2a_SDE`.
2. In the **About** panel, click the gear icon.
3. Add these topics:

- `home-assistant`
- `hacs`
- `water`
- `water-meter`
- `water-consumption`
- `m2a`
- `eaupla`
- `mulhouse`
- `france`

HACS filters generic topics such as `home-assistant`, `hacs`,
`custom-component`, and `integration` before validation, so at least one
specific topic such as `water`, `water-meter`, `m2a`, `eaupla`, or `mulhouse`
must be present.

## Description

Recommended repository description:

`Unofficial Home Assistant integration for m2A / Eaupla! water consumption`
