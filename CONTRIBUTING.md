# Contributing

Contributions are welcome.

1. Fork the repository.
2. Create a feature branch.
3. Keep changes focused.
4. Update `CHANGELOG.md` when appropriate.
5. Never commit credentials, JWTs, cookies, session identifiers, household
   addresses, personal data or third-party subscriber data.
6. Open a pull request.
7. HACS validation and Hassfest must pass.

For changes to the private m2A portal API, document the endpoint shape without
publishing real authentication material or personal responses.
